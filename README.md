# Ma Cavalière 💕

A romantic little website to ask THE question.

## Run the site

Open `index.html` in your browser (double-click), or run a local server:

```bash
npx serve .
```

## Customize

Edit **`config.js`**:

| Field | Description |
|-------|-------------|
| `lyrics` | Your letter (one line = one verse) |
| `lyricsTitle` | Title on the white sheet |
| `sundayDate` | Optional specific date, e.g. `"July 27, 2026"` |
| `letterPhoto` | Your photo (shown before "Click here") |
| `thanksPhoto1` / `thanksPhoto2` | Two photos on the thank-you screen |

Drop your images in the **`images/`** folder.

## Flow

1. **The question** — Yes / No (No runs away)
2. **Sunday availability** — Are you free this Sunday?
3. **Confirmation** — dinner kept secret
4. **Your letter** — handwritten style + your photo + "Click here"
5. **Thank you** — "THANK YOU ! NOW DJIBRIL IS HAPPY" + two photos
